PARTE 1 — SISTEMA SIGA (Python Desktop)
================================================================================

Eres un desarrollador experto en Python. El sistema SIGA (Sistema Integral de
Gestión de Impuestos y Ganancias) es una aplicación de escritorio para un abasto
(tienda de víveres) en Maracaibo, Venezuela. Usa CustomTkinter, Pandas, Matplotlib
y MySQL. Tiene dos módulos: Punto de Venta (POS) y Dashboard Gerencial.

ARCHIVOS CREADOS EN /workspaces/default/code/siga/:

1. schema.sql
   - Base de datos MySQL: siga_db
   - Tablas: productos, tasas_historicas, ventas, ventas_detalle,
             gastos_operativos, cierres_fiscales
   - Datos semilla incluidos (10 productos, 7 tasas BCV, 11 ventas de ejemplo)

2. config.py
   - IVA_RATE = 0.16
   - IGTF_RATE = 0.03
   - Paleta de colores dark blue-gray para CustomTkinter
   - DB_CONFIG para conexión MySQL local
   - Constantes de semáforo: STOCK_SUFICIENTE, STOCK_BAJO, STOCK_AGOTADO

3. database.py
   - Clase DatabaseManager con context manager cursor
   - Métodos: get_product_by_code, save_sale (transacción), get_weekly_sales_by_day,
     save_fiscal_closure, get_all_products, get_daily_sales,
     get_total_expenses_day, fecha_tiene_cierre

4. data_processor.py
   - CartProcessor: carrito como DataFrame Pandas, cálculos vectorizados
     de IVA/IGTF, totales fiscales
   - DashboardProcessor: métricas diarias, tendencia semanal, gastos por
     categoría (pie chart), inventario con semáforo, cierre fiscal

5. app.py
   - SIGAApp(ctk.CTk) con dos tabs: POSTab y DashboardTab
   - Matplotlib embebido via FigureCanvasTkAgg
   - Tema dark con paleta azul-gris oscuro

6. requirements.txt
   - customtkinter>=5.2.2, mysql-connector-python>=8.3.0,
     pandas>=2.2.0, matplotlib>=3.8.0, numpy>=1.26.0

UTILIDADES:

src/app/utils/pdfParser.ts
  - Usa pdfjs-dist@6.1.200, worker via CDN
  - leerVentasPdf(file) → ProductoVendido[]
  - leerInventarioPdf(file) → ProductoInventario[]
  - Reconstrucción de tablas: extractItems → groupByRows (Y ±4px) → parseVentasRows/parseInventarioRows
  - Detecta códigos de 5-6 dígitos como inicio de fila
  - colorMargen(pct): ≥60 verde, ≥30 amarillo, rojo
  - estadoStock(p): suficiente / bajo / agotado
  - resumenVentas(prods), resumenInventario(prods)

src/app/utils/taxStorage.ts (NUEVO)
  - Implementa D1 (almacén fiscal) del DFD para la capa web
  - Clave localStorage: "invergica_ventas_YYYY-MM-DD"
  - guardarVentasDia(fecha, totalVentas, totalCosto, totalUtilidad, cantidad)
  - actualizarDivisas(fecha, divisas): el admin ingresa manualmente los montos en USD
  - calcularResumenMes(mes): suma todo el mes, calcula IVA=base×0.16 y IGTF=divisas×0.03
  - IVA_RATE = 0.16, IGTF_RATE = 0.03 (constantes del DFD Nivel 3)
  - vencimientoSENIAT(mes): día 15 del mes siguiente
  - diasParaVencimiento(mes): días enteros hasta vencer
