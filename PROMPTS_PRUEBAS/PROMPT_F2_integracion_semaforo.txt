CONTEXTO:
Eres un asistente de pruebas para el sistema Invergica Web.
Esta prueba verifica los módulos de inventario y vencimientos de lotes.
DFD Nivel 2: Proceso 3.1 Monitorear Vencimientos → 3.2 Evaluar Alertas → 3.3 Cuantificar Mermas
DFD Nivel 3 (Explosión 3.3): 3.3.1 Leer Fecha → 3.3.2 Restar vs Fecha Actual → 3.3.3 Asignar Color
E-R: PRODUCTO ←Pertenece_A→ LOTE (vencimiento, color_alerta) →Genera→ MERMA (cantidad, motivo)

INVENTARIO DE PRUEBA (7 productos):
  Suficientes (3): Arroz 120/20, Café 40/10, Jabón 90/20
  Bajos (2):       Aceite 3/5, Papel higiénico 2/10
  Agotados (2):    Harina 0/10, Azúcar 0/5

SECCIÓN A: Tests de estadoStock individual
  - Clasificar cada producto del inventario de prueba
  - Verificar todos los suficientes, bajos y agotados

SECCIÓN B: Tests de resumenInventario consolidado
  - Total = 7, suficientes = 3, bajos = 2, agotados = 2
  - listaAgotados contiene Harina y Azúcar (por código)
  - listaBajos contiene Aceite y Papel (por código)
  - valorVenta > valorCosto (margen positivo)
  - Producto agotado NO suma valor (existencia = 0)

SECCIÓN C: colorAlertaLote (DFD 3.3.3 Asignar Color de Alerta)
  Función: colorAlertaLote(vencimientoISO: string): "verde" | "amarillo" | "rojo"
  Reglas:
    - diasRestantes ≤ 0  → "rojo"    (vencido o vence hoy)
    - diasRestantes ≤ 30 → "amarillo" (próximo a vencer)
    - diasRestantes > 30 → "verde"   (en buen estado)
  Casos:
    - Fecha 2020-01-01 (pasada) → rojo
    - Fecha de hoy + 15 días → amarillo
    - Fecha de hoy + 60 días → verde

SECCIÓN D: diasHastaVencimiento (DFD 3.3.2 Restar vs Fecha Actual)
  Función: diasHastaVencimiento(vencimientoISO: string): number
  Casos:
    - Fecha pasada → número negativo
    - Fecha futura (hoy + 30) → número positivo
    - Resultado es siempre entero (Math.ceil)

SECCIÓN E: calcularMermaPorLote (E-R: LOTE →Genera→ MERMA)
  interface Merma { id, cantidad, motivo, loteId }
  Función: calcularMermaPorLote(mermas, loteId) → number
  Casos:
    - Lote con 2 mermas (vencimiento + daño físico) → suma ambas
    - Lote sin mermas → 0
    - Múltiples motivos en mismo lote se acumulan

HERRAMIENTAS: vitest, describe/it/expect
NOTA: colorAlertaLote y diasHastaVencimiento son funciones helper que
      implementas dentro del archivo de prueba (no están en pdfParser.ts todavía)
