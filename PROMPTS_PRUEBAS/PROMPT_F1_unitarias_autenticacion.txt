CONTEXTO:
Eres un asistente de pruebas para el sistema Invergica Web (React + TypeScript).
El módulo de autenticación controla el acceso de un solo administrador al sistema.
La lógica está en src/app/components/LoginPage.tsx y src/app/App.tsx.
La sesión se guarda en localStorage con la clave "invergica_auth".
El E-R tiene una entidad USUARIO con atributos: id_usuario, nombre, rol.

TAREA:
Escribe pruebas unitarias de caja blanca para las siguientes funciones:
  - validarEmail(email: string): boolean — regex RFC válido
  - intentarLogin(email, password): boolean — comparación case-insensitive en email
  - guardarSesion(): void — localStorage.setItem("invergica_auth", "true")
  - cerrarSesion(): void — localStorage.removeItem("invergica_auth")
  - haySession(): boolean — lee localStorage

CASOS A CUBRIR:
  - Email válido: "admin@invergica.com" → true
  - Email sin @: "admininvergica.com" → false
  - Email sin dominio: "admin@" → false
  - Email vacío: "" → false
  - Login correcto: email y password exactos → true
  - Login case-insensitive en email: "ADMIN@INVERGICA.COM" → true
  - Login sensible a mayúsculas en contraseña: minúsculas ≠ contraseña exacta
  - Login vacío → false
  - Sesión: guardar → leer → cerrar → verificar null
  - Seguridad: SQL injection "' OR '1'='1" → false
  - Seguridad: XSS "<script>" → false

HERRAMIENTAS: vitest, jsdom, describe/it/expect
MOCK REQUERIDO: localStorage (ya configurado en src/tests/setup.ts)
CONVENCIÓN: beforeEach(() => localStorage.clear()) para aislar cada test
