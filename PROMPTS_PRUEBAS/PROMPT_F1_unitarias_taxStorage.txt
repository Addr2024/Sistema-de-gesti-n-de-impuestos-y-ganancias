CONTEXTO:
Eres un asistente de pruebas para el sistema Invergica Web.
taxStorage.ts implementa el almacén D1 del DFD Nivel 1 (BD Transaccional)
usando localStorage. Cubre los Procesos 2.2.1, 2.2.2 y 2.2.3 del DFD Nivel 3.
Entidades E-R relacionadas: CIERRE_CAJA (fecha_cierre, utilidad_neta),
GASTOS_OPERATIVOS (monto), USUARIO (rol = admin).

MÓDULO DFD CUBIERTO:
  2.2.1 Extraer Base Imponible (Bruta) → guardarVentasDia()
  2.2.2 Multiplicar × 0.16 (IVA)      → calcularResumenMes().ivaDeuda
  2.2.3 Filtrar Divisas × 0.03 (IGTF) → calcularResumenMes().igtfDeuda

FUNCIONES A PROBAR:
  - IVA_RATE = 0.16 (constante)
  - IGTF_RATE = 0.03 (constante)
  - guardarVentasDia(fecha, totalVentas, totalCosto, totalUtilidad, cantidadProductos)
  - leerVentasDia(fecha): VentasDia | null
  - actualizarDivisas(fecha, divisas): void
  - leerVentasMes(mes): VentasDia[]
  - calcularResumenMes(mes): ResumenMes
  - mesesConDatos(): string[]
  - vencimientoSENIAT(mes): string  → "YYYY-MM-15" del mes siguiente
  - diasParaVencimiento(mes): number → negativo si ya venció
  - formatearMes(mes): string → "Enero 2026"

CASOS CLAVE A CUBRIR:
  - IVA_RATE exactamente 0.16
  - IGTF_RATE exactamente 0.03
  - guardar día y leerlo de vuelta
  - guardar preserva divisas existentes al reimportar
  - leer fecha inexistente → null
  - actualizar divisas negativas → queda en 0
  - leerVentasMes filtra solo el mes correcto
  - leerVentasMes retorna días ordenados cronológicamente
  - calcularResumenMes: base = suma ventas, iva = base×0.16, igtf = divisas×0.03
  - calcularResumenMes: totalDeuda = iva + igtf
  - calcularResumenMes con mes vacío → todos en 0
  - vencimientoSENIAT("2026-12") → "2027-01-15" (cruce de año)
  - diasParaVencimiento año pasado → número negativo
  - formatearMes("2026-06") → "Junio 2026"

HERRAMIENTAS: vitest, describe/it/expect/beforeEach
MOCK: localStorage simulado en src/tests/setup.ts
IMPORTANTE: beforeEach(() => localStorage.clear()) es crítico para aislar tests
